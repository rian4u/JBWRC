# Benchmark Skill

원자 액션의 기술 후보를 조사하고 비교표를 작성하는 스킬이다.
plan-conventions.md C-2 절차를 일관되게 수행한다.

---

## 실행 모드

### 모드 1: 단일 액션 벤치마크

사용자가 특정 액션이나 기술 주제를 지정한 경우.
예: "CSV 파싱 라이브러리 벤치마크 해줘"

### 모드 2: 기획서 전체 벤치마크

`docs/plan.md`의 모든 `[원자]` 액션을 스캔하여 기술 후보가 없거나 비교표가 없는 항목을 식별하고 순차적으로 벤치마크를 수행한다.

---

## 벤치마크 절차 (C-2 기반)

각 원자 액션에 대해 아래 4단계를 수행한다.

### 1단계: 웹서치

- 해당 액션의 **모범 구현 패턴** 조사
- **주의사항·함정** 조사
- 검색 쿼리 예: "[액션 키워드] best practice [언어/환경]"
- 최소 2~3개 소스 확인

### 2단계: 후보 탐색

- 구현 가능한 도구·라이브러리를 **최소 2개 이상** 식별
- 각 후보의 공식 문서·GitHub 확인
- 최근 업데이트 일자, 스타 수, 이슈 상태 확인

### 3단계: 환경 확인

프로젝트의 현재 환경에서 이미 설치된 것을 식별한다.

```bash
# 사용 환경에 따라 적절한 명령 실행
pip list 2>/dev/null          # Python
npm list --depth=0 2>/dev/null # Node.js
```

설치 여부를 ✅/❌로 표시한다.

### 4단계: 비교표 작성

아래 형식으로 비교표를 작성한다.

```markdown
### [액션명] 기술 벤치마크

| 기준 | 후보 A | 후보 B | (후보 C) |
|------|--------|--------|----------|
| 설명 | ... | ... | ... |
| 장점 | ... | ... | ... |
| 단점 | ... | ... | ... |
| 성능 | ... | ... | ... |
| 학습 곡선 | 낮/중/높 | ... | ... |
| 유지보수 활성도 | 활발/보통/저조 | ... | ... |
| 라이선스 | MIT/Apache/... | ... | ... |
| 비용 | 무료/유료 | ... | ... |
| 현재 환경 | ✅ 설치됨 / ❌ 미설치 | ... | ... |
| **추천** | ✅ / — | ... | ... |

**추천 이유:** (1~2문장으로 근거 명시)
```

---

## 결과 저장

- **모드 1**: 비교표를 사용자에게 출력한다. 기획서가 있으면 해당 액션의 기술 후보란에 반영 여부를 `AskUserQuestion`으로 확인한다.
- **모드 2**: 기획서의 `기술 선택지` 섹션과 `기술 리서치 결과` 섹션에 결과를 반영한다. 반영 전 사용자 승인을 받는다.

---

## 주의사항

- **리서치 없이 비교표를 작성하지 않는다.** 반드시 웹서치를 수행한 후 기재한다.
- 후보가 1개뿐인 경우에도 대안을 찾아본다. 정말 대안이 없으면 "대안 없음 — 사유: ..." 기재.
- 사용자의 선호 언어·프레임워크(프로필 캐시)를 고려하여 후보를 선정한다.
- 유료 도구는 반드시 비용을 명시한다.
- 더 이상 유지보수되지 않는 라이브러리는 후보에서 제외하고 사유를 기재한다.
